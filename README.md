# ChargeFinder
### EV Charging Station Finder with Community-Based Reporting and Verification

## About the Project

ChargeFinder is a web-based application designed to help users find electric vehicle (EV) charging stations and contribute information about missing stations.

The application allows users to explore available charging stations, search by name or area, view station details and submit information about missing stations. Admins can review and verify submitted information before making it publicly available.

## Main Features

- **View Charging Stations:** Browse approved EV charging stations.
- **Search Stations:** Search by station name and area.
- **Station Details:** View available information about charging stations.
- **Community Reporting:** Submit information about missing charging stations.
- **Admin Verification:** Review, approve or reject submitted station information.
