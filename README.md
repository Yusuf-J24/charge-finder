# ChargeFinder

**EV Charging Station Finder with Community-Based Reporting and Verification**

## About the Project
ChargeFinder is a web-based application designed to help users find EV charging stations and report missing station information.

## Main Features
- View available charging stations.
- Search stations by name and area.
- View charging station details.
- Submit information about missing stations.
- Admin verification and approval of submissions.

## Technologies
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript (optional)

## Project Status
Currently under development as an MCA mini project.
